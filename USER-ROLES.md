# User Roles

## Admin

Admin has full access to the system.

Permissions:
- Manage users
- Manage customers
- Manage reservations
- Manage payments
- Manage system settings

## Manager

Manager can manage the main photography operations.

Permissions:
- Manage customers
- Manage reservations
- View payments
- View deposits

## Member

Member has limited access.

Permissions:
- Create reservation
- View own reservation
- View own information

Member cannot manage users or other customers.
