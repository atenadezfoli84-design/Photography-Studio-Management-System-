# Test Cases - Photography Studio Management System

## TC01 - Add Customer

Input:
Customer name and customer information

Expected Result:
The customer should be added successfully.

---

## TC02 - Create Photography Reservation

Input:
Customer name and photography date

Expected Result:
The reservation should be created successfully.

---

## TC03 - Cancel Reservation

Input:
Reservation ID

Expected Result:
The reservation should be cancelled successfully.

---

## TC04 - Add Deposit Amount

Input:
Deposit amount

Expected Result:
The deposit amount should be saved successfully.

---

## TC05 - Invalid Reservation

Input:
Reservation without customer name or photography date

Expected Result:
The system should show an error and the reservation should not be created.
